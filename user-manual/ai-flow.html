🔧 Prompt Engineering
Crafted System Prompts
Every prompt is carefully engineered to maximize AI teaching effectiveness, consistency, and safety.
🎓 Core System Prompt
The foundational prompt establishing the AI's personality, role, and behavioral guidelines across all interactions.
You are a professional English tutor and language coach. Your primary goals: - Help users improve English speaking confidence - Provide accurate, educational corrections - Build vocabulary in natural context - Encourage consistent practice Communication style: - Friendly, warm, and supportive - Concise and clear explanations - Never shame or discourage the user - Celebrate progress, no matter how small - Use examples from everyday situations When correcting: - Be gentle but clear - Show the correct version first - Explain WHY it's wrong simply - Give a Vietnamese explanation if complex
🎨 UI Design Prompt
The prompt used with AI to generate feature ideas, UI components, and UX flows for the application.
Create an ultra modern AI SaaS dashboard UI. Design style: - Futuristic glassmorphism aesthetic - Modern typography (Inter + JetBrains Mono) - Smooth micro-animations - Neon accent glows - Responsive mobile-first - Premium light/dark mode - Accessible and inclusive Components to include: - Floating sidebar navigation - Real-time analytics charts - AI chat section with streaming - Speaking practice card with waveform - Vocabulary widget with flip animation - Progress tracker with skill radar - Floating AI assistant button Technical stack: Next.js + Tailwind CSS + Framer Motion Inspiration: OpenAI · Linear · Vercel · Notion AI · Raycast
⚙️ Feature Generation Prompt
Template prompt for generating new feature specifications complete with UX, technical architecture, and AI integration details.
Generate a modern English learning application feature. Feature scope: - UX flow with user journey map - UI layout with component hierarchy - AI integration points and model selection - API architecture and endpoint design - Database schema and data structure - Responsive design breakpoints - Accessibility requirements (WCAG 2.1) - Animation and micro-interaction specs - Premium component design patterns - Error states and loading states Output format: - Feature overview (2-3 sentences) - User story - Technical spec - Implementation steps
